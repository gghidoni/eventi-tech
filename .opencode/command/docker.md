---
Comandi Docker disponibili:

- `up` o nessun argomento: `docker-compose up -d`
- `down`: `docker-compose down`
- `logs`: `docker-compose logs -f app`
- `restart`: `docker-compose restart`
- `ps`: `docker-compose ps`

Esegui il comando appropriato in base a: $ARGUMENTS
